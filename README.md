## 🚀 Featured Projects

### 🎬 [Movie Recommendation System](https://github.com/VirojaYeshpatel/movie-app)
Machine-learning-powered movie recommender built with **Python, Streamlit, Pandas, NumPy, and scikit-learn**, using collaborative filtering and cosine similarity.

### 🚨 [Alerting & Notification Platform](https://github.com/VirojaYeshpatel/alerting-system)
Backend platform built with **FastAPI, SQLAlchemy, MySQL, and APScheduler** featuring alert management, snoozing, reminders, and analytics.

### 📺 [ASTAFLIX Streaming Dashboard](https://github.com/VirojaYeshpatel/my-streaming-dashboard)
Responsive streaming dashboard built with **Next.js, TypeScript, Tailwind CSS, and TMDB API** with dynamic movie pages and real-time data.

### 🍲 [RecipeScape](https://github.com/VirojaYeshpatel/Recipescape)
Full-stack recipe browsing and search application using **Node.js, Express, PostgreSQL, HTML, CSS, and JavaScript**.

### 🍔 [Food Ordering System](https://github.com/VirojaYeshpatel/food-ordering-system)
Multi-platform project foundation combining a **Node.js/Express backend, React admin panel, and Flutter mobile application**.
